# Choudhury Home — গৃহ সহায়ক

The Choudhury family home companion app. Built for Ma and Baba.

## What it does
Daily needs, entertainment, health, family contacts, security, and golf — all in one tap.

## Files
| File | Purpose |
|------|---------|
| `index.html` | The entire app — single file |
| `manifest.json` | PWA manifest — enables home screen install |
| `icon.png` | App icon 192×192 |
| `icon-512.png` | App icon 512×512 |

## Updating
1. Get the new `index.html` from Claude
2. Go to this repo on GitHub
3. Click `index.html` → Edit (pencil icon) → paste new content → Commit
   — OR —
   Upload Files → drag new `index.html` → Commit changes
4. Vercel auto-deploys in ~20 seconds. URL stays the same.

## Adding to home screen
**iPhone:** Open in Safari → Share → Add to Home Screen → Add  
**Android:** Open in Chrome → Menu (⋮) → Add to Home Screen

## Family access
Share the Vercel URL with everyone. One link, works on any device.
